A graphical method for displaying associations in count/abundance tables

The CA Pipeline

Everything up to the SVD is data preparation. CA itself begins with the SVD on S.

  1. Form the correspondence matrix P
    Divide each count by the grand total n. Each entry pij = xij/n is now a joint proportion.
    P_ij = x_ij / n
  2. Compute row and column margins
    r = P·1 (row totals of P), c = P'·1 (column totals of P). These are the marginal proportions.
  3. Compute residuals from independence
    If P were independent, it would equal rc'. Subtracting removes the trivial marginal structure and isolates the actual row–column associations.
    P − rc'
  4. Standardise for abundance (form S)
    Divide each residual by √(r_i · c_j) so that abundant rows/columns don't dominate. Motivated by Poisson: variance = mean, so this gives unit-variance residuals.
    S = D_r^{−1/2} (P − rc') D_c^{−1/2}
  5. SVD of S → low-rank approximation
    Decompose S = UΛV'. Keep the first s singular values/vectors (usually s = 2 for a biplot). The rank-s approximation minimises the weighted least-squares error.
  6. Choose coordinate scaling and plot
    Convert singular vectors to row and column coordinates. The choice of scaling determines what can and cannot be interpreted in the biplot.

Key Quantities

Row Profiles

The i-th row of D_r⁻¹P. Each entry is x_ij / (row total), so the row profile sums to 1. It tells you the conditional distribution of columns given that row.

r̃_i = row i of D_r⁻¹P

Column Profiles

Analogous to row profiles but for columns. The j-th column of D_c⁻¹P'. Each column profile tells you the conditional distribution of rows given that column.

c̃_j = col j of D_c⁻¹P'

χ² Distance

A weighted Euclidean distance between two row profiles that down-weights abundant columns — a difference in a rare column is more informative than the same difference in a common column.

Σ_j (r̃_ij − r̃_i'j)² / c_j

Total Inertia

The total association in the table — how much the data deviates from independence. Equivalent to χ²/n and to the sum of squared singular values of S.

Inertia = χ²/n = tr[SS'] = Σ λ_k²
all components combined = total inertia
rank-2 approximation captures proportion (λ₁² + λ₂²) / Σλ_k²

What do standard coordinates represent?

In row-principal, the column standard coordinates are "extreme profiles" — each column point represents a hypothetical row whose entire mass sits on that one column. For example, the "heavy" column point represents a job group that is 100% heavy smokers (row profile = [0, 0, 0, 1]).

Real row points are interpreted by which column pole they point towards. If SM lies on the "heavy" arrow, 100% of senior managers are heavy smokers. The further a row is in the direction of a column, the more that column dominates its profile.

You read associations via angles: a small angle between a row arrow and column arrow = strong association.

Visual Encoding in R (mass = TRUE, contrib = "absolute")

⬤
Size / Thickness

Proportional to mass — the relative frequency (r_i for rows, c_j for columns). A thick point is abundant in the data.

⬤
Colour Intensity

Proportional to quality of representation or absolute contribution to the 2D plane. A faded point is poorly captured in 2D — interpret with caution.

→
Arrow Length (rowgreen)

Proportional to contribution to inertia. A long arrow drives the association structure; a short arrow (near origin) contributes little.
