STEP 2: Partition correlation matrix

p = 2
q = 2

rho11 = rho[1:p,1:p]
rho12 = rho[1:p,(p+1):(p+q)]
rho21 = rho[(p+1):(p+q),1:p]
rho22 = rho[(p+1):(p+q),(p+1):(p+q)]
# rho11;rho12;rho21;rho22

STEP 3: Calculate intermediate matrices

# Calculate inverse: 
rho11_inv = solve(rho11)
rho22_inv = solve(rho22)

# Perfrom eigen-decomposition:
rho11_eig = eigen(rho11_inv)
rho22_eig = eigen(rho22_inv) 

# Calculate inv_sqrt:
rho11_inv_sqrt = rho11_eig$vectors%*%diag(sqrt(rho11_eig$values))%*%t(rho11_eig$vectors)
rho22_inv_sqrt = rho22_eig$vectors%*%diag(sqrt(rho22_eig$values))%*%t(rho22_eig$vectors)

STEP 4: Compute matrix R and eigen-decomposition

R = rho11_inv_sqrt%*%rho12%*%rho22_inv%*%rho21%*%rho11_inv_sqrt
R_eig = eigen(R)

STEP 5: Obtain canonical correlations

R_star = sqrt(R_eig$values)
R_star
[1] 0.73872731 0.03014884

This describes the strength of the linear relationship between the two canonical variates.

p = 10       # number of variables

# Common covariance: diagonal matrix with variance 3 on X1, and 1 on X2–X10

# Define group means so that they differ along the first five dimensions:
means = lapply(1:5, function(i) {

STEP 2: Calculate B

B = Reduce(`+`,
           lapply(1:g,function(i){
             n_i[i]*(bar_group[i,]-bar_overall)%*%t(bar_group[i,]-bar_overall)
           }))

STEP 3: Calculate W

W = Reduce(`+`,
           lapply(1:g,function(i){
             Xi = X[dat$group==i,]
             cov(Xi)*(n_i[i]-1)
           }))

STEP 4: Eigen decomposition

mat     = solve(W)%*%B

S_pooled = W/(sum(n_i)-g)

STEP 1: Compute g, ni, x_bar, xi

dat$group = as.numeric(as.factor(dat$segment))
X = dat[,-1]
X = as.matrix(X[,-11])

g   = length(unique(dat$segment))
n_i = table(dat$segment)

bar_overall = colMeans(X)
bar_groups  = dat |>
  dplyr::group_by(segment) |>
  dplyr::summarise(
    dplyr::across(everything(),mean),
    .groups='drop'
  ) |>
  dplyr::select(-segment) |>
  dplyr::select(-group) |>
  as.matrix()

STEP 2: Calculate B

B = Reduce(`+`,lapply(1:g,function(i){
  n_i[i]*(bar_groups[i,]-bar_overall)%*%t(bar_groups[i,]-bar_overall)
}))

STEP 3: Calculate W

W = Reduce(`+`,lapply(1:g,function(i){
  Xi = X[dat$group==i,]
  cov(Xi)*(n_i[i]-1)
}))

STEP 4: Eigen decomposition

mat = solve(W)%*%B

eig_mat = eigen(mat)
eig_vec = eig_mat$vectors |> Re()

S_pooled = W/(sum(n_i)-g)

sd_vec = diag(t(eig_vec)%*%S_pooled%*%eig_vec) |> sqrt()

sol = eig_vec%*%diag(1/sd_vec)
sol = sol[,1:2]

LD1 separates Budget shoppers and Occasional browsers from the other groups. This indicates that BS and OB have low values of average spend and visiting frequency. LD2 separates Young trendsetters from the other groups. Both LD1 and LD2 separate YT from the remaining groups. This indicates that YT have high values of average spend and visiting frequency as well as high values of online ratio and session length. BS and OB both have similar values of variables and are difficult to distinguish. Similarly, LR and PR have similar values for both LD1 and LD2.

When does the LDA algorithm break down? W becomes singular when group sizes are small relative to the number of variables. solve(W) from first principles will throw an error since W is not of full rank.
